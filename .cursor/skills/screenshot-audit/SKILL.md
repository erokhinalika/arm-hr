# Screenshot Audit Skill

## Goal
Evaluate the prototype as a set of screens, not isolated pages.

## Inputs
- `context/ui-checklist.md`
- exported screenshots or visible browser screens
- target HTML/CSS files

## Review checklist
- Navigation/sidebar consistency
- Header/action consistency
- Card density and rhythm
- Table/list readability
- Empty/loading state clarity
- Funnel status readability
- Drawer/modal layering
- Bank screens consistency with core ARM screens

## Output
Provide a ranked visual QA list: critical, important, nice-to-have. Include exact file/class targets when possible.
