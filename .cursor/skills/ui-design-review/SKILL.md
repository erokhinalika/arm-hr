# UI Design Review Skill

## Goal
Produce a senior product-design critique before implementation.

## Steps
1. Identify the screen and read the relevant context files.
2. Inspect the HTML structure and related CSS.
3. Review the screen across these dimensions:
   - visual hierarchy,
   - spacing rhythm,
   - typography,
   - color/contrast,
   - component consistency,
   - information density,
   - primary/secondary action clarity,
   - recruiter workflow clarity.
4. Return a short ranked list of problems.
5. Propose a focused improvement pass that can be done without changing product scope.

## Output
- Start with the 3 highest-impact issues.
- Then list the smallest safe changes.
- Do not implement until the user asks for implementation, unless the task explicitly says to fix it.
