# HR ARM Modern Prototype

## Overview
This is a modern React + Tailwind CSS prototype for the HR Recruiter command center.

## Stack
- React 18
- Vite
- Tailwind CSS
- Lucide Icons

## Design Direction
- **Linear/Ashby aesthetic**: Dense, operational, neutral.
- **Operational focus**: High information density, clear actions.

## Development
- `npm run dev`: Start development server.
- `npm run build`: Build for production.
